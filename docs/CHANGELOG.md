# Orbital Edition 变更说明

## 范围

两个用户压缩包中的 Web 主文件和原始截图经比对一致。本次只修改独立 Web 产品页，不修改后端、小程序和 Node Daemon。

## 重设计

重写 `index.html`、`styles.css` 和 `app.js`；增加 `src/scene.js`、锁定的 Three.js 加载入口、本地依赖复制脚本、预览服务器、测试脚本与文档。页面从原先的简洁展示改为深色轨道控制台：强对比标题、绿色光照、玻璃信息面板、倾斜设备框、功能网格、传输结构图与金属隐私卡。

原始七张 PNG 未修改；Agent 图标沿用完整工程素材。新增标识 SVG 仅用于网页 favicon。

## 页面交互

导航、移动菜单、FAQ 与滚动展示保留并重做。新增真实截图切换与原图弹窗、本地审批状态演示、接入指南及命令复制。3D 场景与页面交互相互独立，依赖失败时不阻断普通页面。

## 文案与状态

依据随附 `WeAgent-Node/README.md`、`WeAgent-Frontend/README.md`、`WeAgent-Backend/README.md` 的能力边界，避免将旧页的扩展规划当作已完成能力。

明确区分 Codex / Pi / Claude Code 原生适配与其他扩展规划；Diff 等功能按适配器能力说明；将网络事件补齐与进程重启后的执行恢复区分；说明消息、工具输出和 Diff 中可能包含经网关传输的代码片段。

页面不制造真实在线设备、远程执行结果、正式二维码或未提供的发布入口。所有可点击演示均注明本地性质。

## 测试修正

修复脚本收尾语法、320–640 像素装饰轨道导致的横向溢出，以及功能网格末行布局。提高移动端正文与按钮字号，保留系统减少动态效果与键盘可访问性。

实际完成的测试与未完成的 WebGL 验证请参见 `TEST-REPORT.md`，不要把已写入的动画和性能控制代码等同于已在真实设备测得的结果。
